Have another question? Get in touch ↗

Does it block apps or enforce limits?

No. The current version measures usage; it does not block apps or enforce time limits.

What needs to be installed?

Install Screen Time on the child’s Android tablet and allow usage access. Parents review activity in the web dashboard.

Do these screenshots show real children’s activity?

No. Names, devices and activity were created only for this demo.
